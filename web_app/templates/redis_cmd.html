常用命令示例

命令说明
SCAN 0游标遍历 Key（推荐替代 KEYS）
DBSIZE当前数据库 Key 数量
INFO serverRedis 服务器信息
GET key名获取指定 Key 的值
TYPE key名查看 Key 的类型

Redis 持久化命令

命令说明
BGSAVE后台异步保存 RDB 快照（推荐）
SAVE同步保存 RDB 快照（阻塞）
LASTSAVE最后一次成功保存时间戳
INFO persistence持久化状态
CONFIG GET dirRDB 文件存储目录
CONFIG GET dbfilenameRDB 文件名
CONFIG SET save ""禁用自动 RDB 快照
CONFIG SET save "900 1"恢复自动快照策略

恢复流程：
1. PING 确认运行 → 2. CONFIG GET dir + dbfilename 定位 RDB
3. 暂停 Worker 写入 → 4. BGSAVE 备份 → 5. SHUTDOWN NOSAVE
6. 替换 RDB → 7. 重启 Redis → 8. DBSIZE 验证

注意：RDB 恢复是全量替换，会覆盖当前所有数据，建议先 BGSAVE。
